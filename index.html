Meet CorkBot.

A compact robot with interchangeable tools and bases. For drawing, making, and hands-on exploration.

Explore the robot ↓

The robot

Start with a pen.
Take it from there.

CorkBot brings robotic motion to your desk. The pen tool turns it into a drawing machine; interchangeable attachments open up new ways to work with objects.

We’re developing the tools and bases around one compact robotic core, so each configuration builds on the same machine.

A small footprint.
A useful working area.

Designed for the workbench, with an aluminum structure, integrated battery, and a shared mounting interface for tools.
